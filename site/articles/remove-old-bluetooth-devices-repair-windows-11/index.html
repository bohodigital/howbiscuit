How to Remove Old Bluetooth Devices and Re-Pair Them in Windows 11

Removing a device from Windows clears that PC’s pairing record. It may remain paired with a phone, another computer, or the accessory’s own remembered-device list.

Updated Aug 5, 2026 4 min read Researched Not hands-on tested
Disclosure

This article contains no paid or affiliate links.

Read the disclosure

What to know

  • Removing a device from Windows clears that PC’s pairing record. It may remain paired with a phone, another computer, or the accessory’s own remembered-device list.
  • Remove the stale Windows pairing, stop competing connections, put the accessory into genuine pairing mode, and add it again.

Open:

Settings → Bluetooth & devices → Devices

Find the old device, select its menu, and choose Remove device.

To pair it again:

Settings → Bluetooth & devices → Add device → Bluetooth

Removing and pairing are separate operations. Removing a device from Windows does not necessarily erase the accessory’s own memory or remove it from other phones and computers.

Remove devices you no longer control

Review the list for:

  • Old headphones
  • Sold phone
  • Former keyboard
  • Replacement mouse
  • Rental vehicle
  • Old controller
  • Returned warranty device
  • Duplicate device names

Removing stale entries makes the list easier to interpret and reduces accidental reconnection.

It does not remotely wipe, disable, or factory-reset the physical accessory.

Record settings before removing an active device

Before removing something you still use, record:

  • Manufacturer and model
  • Current device name
  • Pairing procedure
  • Companion application
  • Firmware tool
  • Multipoint configuration
  • Custom button assignments
  • Accessibility settings

Some accessories lose customization after a factory reset.

Do not reset a hearing, communication, medical, or accessibility device without its support instructions and a working recovery plan.

Remove the Windows pairing

  1. Open Settings.
  2. Select Bluetooth & devices.
  3. Select Devices.
  4. Find the accessory.
  5. Select More options.
  6. Select Remove device.
  7. Confirm.

Restart Windows when the device remains visible or reconnects unexpectedly.

Stop competing connections

A headset or speaker may still be paired with:

  • Phone
  • Tablet
  • Television
  • Second computer
  • Vehicle
  • Game console

Turn Bluetooth off on competing devices during re-pairing.

A multipoint accessory may reconnect to another remembered device before Windows finishes discovering it. The accessory is not disloyal. It is following a connection order humans configured and then forgot.

Clear the accessory’s pairing memory

Some accessories remember only a limited number of devices.

Use the manufacturer’s instructions to:

  • Clear all pairings
  • Reset Bluetooth only
  • Enter pairing mode
  • Select a multipoint slot

Do not guess a button combination. Holding several buttons for an adventurous length of time may factory-reset unrelated settings.

Put the accessory in discoverable mode

Powered on is not the same as discoverable.

Common indicators include:

  • Flashing blue light
  • Alternating colors
  • Audible pairing prompt
  • Pair button held for a specified period

Keep the accessory charged, close to the PC, and disconnected from competing hosts.

Add it again

  1. Turn Windows Bluetooth on.
  2. Open Add device.
  3. Select Bluetooth.
  4. Wait for the exact device name.
  5. Select it.
  6. Verify any displayed code.
  7. Complete pairing.
  8. Test input and output.

Do not approve an unexpected code or pair an unidentified similarly named device in a crowded location.

Select the correct audio device

After pairing headphones or speakers:

  1. Open Settings → System → Sound.
  2. Choose the device under Output.
  3. Select the intended microphone under Input.
  4. Test volume and microphone.
  5. Review application-specific settings.

Some headsets expose separate high-quality playback and call-oriented modes. An application may continue using the old default until restarted.

Phone Link is separate

Removing a phone from the Bluetooth list does not necessarily remove it from Phone Link or a Microsoft-account mobile-device relationship.

Review:

  • Settings → Bluetooth & devices → Mobile devices
  • Phone Link settings
  • Link to Windows on the phone
  • Microsoft-account device list

When removal or pairing fails

Try, in order:

  1. Restart the PC.
  2. Restart the accessory.
  3. Install Windows updates.
  4. Check the accessory application.
  5. Update the Bluetooth adapter from the PC manufacturer.
  6. Reset the accessory according to its manual.
  7. Reinstall the adapter driver only after ordinary steps fail.

Do not install a generic driver from a third-party driver-download site.

Bottom line

Remove the stale Windows pairing, stop competing connections, put the accessory into genuine pairing mode, and add it again.

Windows can forget its side of the relationship. The headphones may still be emotionally attached to three phones, a television, and a laptop recycled years ago.
