Home Network Device Inventory Template: Know What Is Connected

Record each device's owner, type, manufacturer, model, network name, hardware address when needed, account, update method, support status, location, and retirement plan. Compare the inventory with the router's client list and investigate unknown devices.

Updated Aug 3, 2026 4 min read Researched Testing not applicable

Read the disclosure

What to know

  • A router client list shows current connections, while the inventory explains who owns each device and how it is maintained.
  • Do not publish MAC addresses, serial numbers, Wi-Fi credentials, recovery codes, or camera locations.
  • Unsupported connected devices should be isolated, replaced, or removed rather than silently left online.

A home network can accumulate devices faster than a household remembers them: old phones, printers, streaming boxes, cameras, doorbells, speakers, thermostats, appliances, game systems, guest devices, and hubs. An inventory connects the router’s anonymous client list to real owners and maintenance decisions.

Copy-ready inventory columns

Use these fields in a private spreadsheet or password-protected note:

Device ID | Friendly name | Owner | Type | Manufacturer | Model | Serial | MAC or network identifier | Connection | Network or VLAN | Account | Update method | Last update check | Support end | Location | Data collected | Retirement status | Notes

A compact example:

NET-018 | Living-room TV | Household | Smart TV | Brand | Model | Private record | Private record | Wi-Fi | IoT network | family-email | Automatic | 2026-08-03 | Unknown | Living room | Viewing + voice status | Active | Review support

Keep exact identifiers and locations private.

Start with the router client list

Open the router’s official app or local administration page. Record every currently connected device and any recently seen device list the router provides.

Names may be vague, such as android-1234, ESP_9A21, or Unknown. Match them by temporarily disconnecting one known device, checking manufacturer prefixes, or viewing the device’s own network settings.

Do not block an unknown device until you consider guests, randomized phone addresses, smart-home bridges, printers, and building equipment. Investigate methodically.

Assign a stable friendly name

Give each device a name that remains meaningful even if the router label changes:

  • Sam-work-laptop
  • Kitchen-speaker
  • Front-doorbell
  • Guest-room-TV
  • Basement-dehumidifier

Include the owner or responsible person. Shared devices should have a household owner and a designated administrator.

Record accounts and update paths

For each connected product, note which email or account manages it, whether multifactor authentication is enabled, and how updates arrive. Do not put passwords in the inventory. Store them in a password manager.

The Federal Trade Commission recommends changing default passwords, using multifactor authentication when available, keeping device software updated, and understanding what data connected products collect. [1]

A device with no known administrator and no update method is a maintenance risk even when it appears to work.

Track support status

Record the last time the manufacturer published software or security information. Add a review date for products that are old, discontinued, or dependent on a cloud service.

Unsupported devices should be removed, replaced, isolated on a guest or IoT network when the router supports it, or used offline if that preserves their useful function. Network isolation reduces exposure but does not make a vulnerable product safe in every scenario.

Separate sensitive device types

Flag cameras, microphones, locks, alarm systems, health-related devices, children’s devices, work computers, and network storage. Record who can access them and whether remote access is enabled.

Do not write camera positions, lock codes, recovery keys, or alarm details in a file stored without encryption. For managed work equipment, follow employer policy rather than changing security settings yourself.

Document network infrastructure

Create records for the modem, router, mesh nodes, switches, access points, and hubs. Include:

  • Model and serial number.
  • Firmware update method.
  • Administrator account owner.
  • Installation and replacement date.
  • Internet provider and support contact.
  • Backup configuration location.
  • Guest-network and IoT-network use.

Do not store the router administrator password in plain text. Record only that it exists in the household password manager.

Reconcile quarterly

Every three months, compare the inventory with the live client list. Mark devices as active, offline, retired, sold, recycled, lost, or unknown.

When a device leaves the household, sign out, remove personal data, revoke cloud access, delete it from household accounts, and remove its router reservation or access rule when appropriate. Follow the manufacturer’s reset procedure before sale or recycling.

Respond to an unknown device

Change the Wi-Fi password and review router security when you have credible evidence of unauthorized access. Reconnect known devices deliberately, use WPA2 or WPA3 as supported, update router firmware, and disable obsolete insecure features.

Do not accuse a neighbor or visitor based solely on a client label. Preserve timestamps and router logs if available.

Minimal version

For a small household, use:

Friendly name | Owner | Model | Account | Updates current | Support status | Retired

The inventory succeeds when every connected device has a known owner, update path, account, and end-of-life decision. A network becomes manageable when “unknown” is temporary rather than permanent.

Limits and cautions

  • Router labels, device names, MAC randomization, cloud accounts, update support, and network-segmentation features vary by manufacturer and software version.
