Why Is My Computer Storage Full?

Use the operating system’s storage report to identify the largest category before deleting anything. Full drives usually result from applications, downloads, media, temporary files, cloud files kept locally, device backups, or one unexpectedly large folder.

Updated Aug 3, 2026 4 min read Researched Not hands-on tested
Disclosure

This article contains no paid or affiliate links.

Read the disclosure

What to know

  • Open Windows Storage or macOS Storage and let the category report finish calculating.
  • Start with downloads, temporary files, Recycle Bin or Trash, unused applications, old backups, and replaceable offline media.
  • Review every cleanup category before confirming because previous operating-system installations and other items can be irreversible to remove.
  • Do not manually delete unknown System, Windows, Library, or application-support folders.

The direct answer

Your computer’s storage is usually full because one or more large categories have grown gradually:

  • Applications and games.
  • Downloads.
  • Videos and photographs.
  • Temporary files.
  • Recycle Bin or Trash.
  • Cloud files stored offline.
  • Old phone or tablet backups.
  • Email attachments.
  • Previous operating-system files.
  • Virtual machines, development tools, or project archives.

Open the operating system’s storage report before deleting anything. Windows and macOS both show where space is being used. [1] [2]

Check the storage categories

Windows

Open:

Settings → System → Storage

Windows shows installed applications, temporary files, documents, pictures, cloud content, and system storage. Microsoft also provides Cleanup recommendations and Storage Sense. [1]

Mac

Open:

Apple menu → System Settings → General → Storage

macOS reports storage by category and provides options for managing applications, documents, messages, media, and Trash. [2]

Wait for the categories to finish calculating.

Start with Downloads

Downloads commonly contains old installers, ZIP archives, duplicate documents, videos, disk images, exported data, and files copied elsewhere.

Sort by size and date. Open or identify unfamiliar files before removing them. Do not delete a tax record, project archive, encryption key, or purchased media merely because it is large.

Review applications and games

Applications may use more space than their listing suggests because they maintain downloaded assets, projects, plug-ins, caches, virtual machines, offline maps, video-rendering files, or local artificial-intelligence models.

Use the operating system’s uninstall process.

Before removing specialized software, confirm that you retain the installer, license access, project files, exported presets, and any local application data you need.

Clear temporary files carefully

Windows can remove temporary files, update remnants, and Recycle Bin contents through Storage settings.

Review every selected category. Microsoft warns that deleting a previous Windows installation removes the ability to return to the earlier version. [1]

On a Mac, use Storage settings and application-specific cleanup rather than deleting unknown items from Library or System folders.

Avoid unfamiliar cleaner applications promising to fix thousands of registry errors. The storage problem does not need an advertising toolbar.

Empty Recycle Bin or Trash

Deleted files continue using space until the bin is emptied.

Before emptying it, review recent large items and restore anything removed accidentally. Cloud services can maintain separate online trash folders.

Check cloud files kept locally

OneDrive, iCloud Drive, Dropbox, and similar services can keep full local copies.

Windows Cleanup recommendations can identify files synchronized to the cloud, and OneDrive Files On-Demand can make eligible files online-only. [1]

macOS Optimize Storage can retain eligible cloud files on demand. [2]

Before removing local copies, consider whether you need them while traveling, during an outage, or for an independent offline backup.

Look for old device backups

Computers used to back up phones and tablets can contain several historical backups.

Apple includes old device backups among the items worth reviewing on a full Mac. [2]

Do not delete the only copy of photographs, messages, authentication data, or an old device state you may need.

Investigate System Data rather than attacking it

Large System, Other, or System Data categories can include caches, logs, application-support files, local snapshots, virtual memory, device backups, plug-ins, and temporary installation data.

Restart the computer and allow pending updates to finish before treating the category as corruption.

Do not delete system directories based on instructions written for another operating-system version.

Search for large files

Useful extensions and categories include:

  • ZIP archives.
  • ISO and DMG images.
  • MOV and MP4 video.
  • Virtual-machine images.
  • Databases.
  • Old exports.
  • Duplicate photo libraries.
  • Recorded meetings.
  • Screen recordings.

Move archival files to a properly backed-up external drive when they do not need to remain internally. Confirm the copy opens before deleting the original.

Keep working space available

A nearly full system drive can interfere with updates, temporary files, virtual memory, browser caches, synchronization, video editing, and general performance. Microsoft notes that low disk space can reduce performance and block Windows updates. [1]

There is no universal percentage every computer must keep free, but repeatedly operating with only a few hundred megabytes available is not sustainable.

Bottom line

Use the built-in storage report to find the largest category before deleting files.

Start with downloads, temporary files, unused applications, old backups, and unneeded local cloud copies. Avoid unknown system folders, verify important backups, and change one category at a time so you know what actually freed the space.

Limits and cautions

  • Storage category names are broad and can take time to recalculate.
  • Cloud synchronization is not automatically a backup against deletion, ransomware, account loss, or provider failure.
  • The amount of free working space needed varies by operating system and workload.
