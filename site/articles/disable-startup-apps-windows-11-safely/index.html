How to Disable Startup Apps in Windows 11 Without Breaking Anything

Startup apps can slow sign-in and continue using memory, disk, processor, and network resources. Disabling startup does not uninstall the application.

Updated Aug 5, 2026 4 min read Researched Not hands-on tested
Disclosure

This article contains no paid or affiliate links.

Read the disclosure

What to know

  • Startup apps can slow sign-in and continue using memory, disk, processor, and network resources. Disabling startup does not uninstall the application.
  • Sort startup apps by impact, identify each application, disable nonessential entries gradually, and test after every change.

Press:

Ctrl + Shift + Esc

Open Startup apps in Task Manager.

Sort by Startup impact.

Disable applications that do not need to launch automatically, then restart and test the functions you actually use.

Microsoft says startup applications can slow startup and increase background activity. Task Manager provides the detailed list and its measured impact categories.

What disabling startup does

Disabling a startup entry normally means:

  • The application remains installed.
  • You can open it manually.
  • It does not automatically launch at sign-in.
  • Its background synchronization or alerts may not begin until it is opened.

It does not necessarily disable:

  • Windows service
  • Scheduled task
  • Browser extension
  • Driver
  • Antivirus component
  • Cloud synchronization configured through another mechanism

Startup applications are only one source of background activity.

Create a baseline

Before changing anything, record:

  • Time from power-on to usable desktop
  • Time from sign-in to settled disk activity
  • Task Manager startup list
  • Applications you expect to open automatically
  • Missing notifications or synchronization problems already present

Take screenshots.

Microsoft recommends keeping track of disabled items during clean-boot troubleshooting so they can be restored later.

Review Startup apps

In Task Manager, inspect:

  • Name
  • Publisher
  • Status
  • Startup impact

Impact can appear as:

  • High
  • Medium
  • Low
  • Not measured

A High result means Windows measured relatively significant startup resource use. It does not prove the application is unnecessary.

A backup client may have high impact and still be important. A low-impact coupon application may still deserve exile on principle.

Usually reasonable candidates

Applications often safe to disable from startup include optional:

  • Game launcher
  • Music client
  • Meeting application
  • Chat application
  • Printer utility
  • Updater tray icon
  • Shopping assistant
  • Device-lighting control
  • Cloud client you do not use

Confirm the exact publisher and function first.

Do not disable a mystery entry merely because its name consists of letters and numbers. Search the installed application path and publisher through official sources.

Treat these cautiously

Investigate before disabling:

  • Antivirus
  • Endpoint security
  • Backup agent
  • Password manager
  • Accessibility software
  • Audio enhancement required by the device
  • Touchpad or hotkey utility
  • VPN required for work
  • Encryption or authentication software
  • Cloud synchronization holding unsaved files

Disabling an interface tray icon may or may not stop the underlying service.

Do not assume the absence of a visible icon means protection stopped, or that the presence of an icon proves protection works.

Disable one group at a time

  1. Disable one or two nonessential items.
  2. Restart Windows.
  3. Test sign-in.
  4. Open normal applications.
  5. Check synchronization.
  6. Test sound, keyboard shortcuts, touchpad, printing, and notifications.
  7. Leave the system for a normal work period.
  8. Reenable anything useful.

Changing 25 entries at once creates a fast computer and a slow investigation.

Settings provides another interface

Open:

Settings → Apps → Startup

Windows displays startup-capable applications with on/off controls.

Task Manager is more useful for troubleshooting because it also shows startup impact. Microsoft documents both interfaces as controlling the same general startup list.

Restartable applications are separate

Windows can reopen supported applications after sign-in.

Open:

Settings → Accounts → Sign-in options

Review:

Automatically save my restartable apps and restart them when I sign back in

Microsoft documents this setting separately from ordinary application startup and specifically references it when preventing Microsoft Edge from reopening automatically.

An application reopening does not always mean it has an enabled Startup apps entry.

Clean boot is a diagnostic tool

When disabling ordinary startup entries does not isolate the slowdown, Microsoft’s clean-boot process can temporarily disable non-Microsoft services and startup applications.

Use clean boot only as a controlled diagnostic process:

  • Hide Microsoft services first.
  • Document every change.
  • Restore normal startup afterward.

A clean boot is not a permanent optimization preset. Leaving required services disabled because the desktop appeared faster is how printing, audio, backup, and updates become tomorrow’s unrelated mysteries.

Check actual resource use

After sign-in, use Task Manager to review:

  • CPU
  • Memory
  • Disk
  • Network

Microsoft describes Task Manager as both a system monitor and startup manager.

An application may have little startup impact but consume substantial resources later.

Bottom line

Sort startup apps by impact, identify each application, disable nonessential entries gradually, and test after every change.

Disabling startup does not uninstall software. It merely ends the assumption that every installed program deserves to attend the first seconds of every Windows session.
