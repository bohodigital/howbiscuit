How to Stop OneDrive Folder Backup Without Losing Your Desktop or Documents

Stopping OneDrive backup changes where Desktop, Documents, or Pictures live. It does not necessarily delete the files, but choosing the wrong destination or deleting synchronized copies afterward can make them disappear from multiple devices.

Updated Aug 5, 2026 4 min read Researched Not hands-on tested
Disclosure

This article contains no paid or affiliate links.

Read the disclosure

What to know

  • Stopping OneDrive backup changes where Desktop, Documents, or Pictures live. It does not necessarily delete the files, but choosing the wrong destination or deleting synchronized copies afterward can make them disappear from multiple devices.
  • Download cloud-only files, stop backup through **Manage backup**, and deliberately choose whether the files belong on the PC or in OneDrive.

Open OneDrive settings:

OneDrive cloud icon → Help & Settings → Settings → Sync and backup → Manage backup

Turn off the folder you no longer want OneDrive to back up.

Current OneDrive versions can offer two different outcomes:

  • Keep the files only in OneDrive.
  • Keep the files only on the PC.

Read the choice carefully. They are not poetic variations of the same button. They move the files in opposite directions.

Back up the files first

Before changing folder backup:

  1. Copy irreplaceable files to another physical drive or protected backup.
  2. Verify the copy opens.
  3. Check OneDrive for synchronization errors.
  4. Confirm which Microsoft or work account is signed in.
  5. Photograph or record the current folder paths.
  6. Close documents and applications using those folders.

OneDrive synchronization is not an independent backup against every mistake. A deletion can synchronize across connected devices.

Confirm which folders are protected

In Manage backup, review:

  • Desktop
  • Documents
  • Pictures
  • Music
  • Videos

The available set depends on the account and OneDrive version.

Also open File Explorer and inspect paths such as:

C:\Users\YourName\OneDrive\Desktop
C:\Users\YourName\OneDrive\Documents
C:\Users\YourName\OneDrive\Pictures

Compare them with the ordinary local paths:

C:\Users\YourName\Desktop
C:\Users\YourName\Documents
C:\Users\YourName\Pictures

Do not assume the folder shown as “Documents” is local merely because File Explorer gives it a friendly name.

Download cloud-only files

A cloud icon beside a file means it may not have a complete local copy.

Before choosing Keep files only on my PC:

  1. Open the backed-up folder in File Explorer.
  2. Right-click the folder or required files.
  3. Select Always keep on this device.
  4. Wait until the files show the appropriate local-availability status.
  5. Open several files while the internet is disconnected as a test.

Microsoft warns that cloud-only files must be downloaded before OneDrive can move them back to a local folder.

Choose “Keep files only on my PC”

Choose this when:

  • You no longer want the folder stored in OneDrive.
  • The computer should retain the working files.
  • Another backup already protects them.
  • The files have been downloaded fully.

Afterward, verify that the content appears in the local Desktop, Documents, or Pictures folder.

Do not immediately delete the old OneDrive folder. Compare:

  • File count
  • Folder structure
  • Important recent documents
  • Hidden or application-created folders
  • File sizes

Only remove duplicates after the new local folder and separate backup have been verified.

Choose “Keep files only in OneDrive”

Choose this when:

  • The cloud copy should remain.
  • You deliberately want the local folder emptied.
  • The files will be accessed through OneDrive.
  • The computer has limited storage.

Microsoft says this option removes the files from the computer while retaining them in OneDrive.

Before choosing it, confirm that:

  • Synchronization is complete.
  • The OneDrive website shows the files.
  • Another device can open a representative sample.
  • Account recovery methods are current.
  • The OneDrive storage plan has enough capacity.

Understand the “Where are my files?” shortcut

After backup is stopped, Windows may leave a Where are my files? shortcut in the original folder.

That shortcut points to the OneDrive location.

It is not another copy.

Deleting the shortcut does not move the underlying files back. Microsoft instructs users who want local copies to move the files manually from OneDrive into the ordinary device folder.

Moving files manually

When the automatic move is incomplete:

  1. Open the OneDrive folder.
  2. Open the local folder in another File Explorer window.
  3. Copy, rather than move, a small test group.
  4. Verify the copied files.
  5. Copy the remaining files in manageable batches.
  6. Compare the source and destination.
  7. Preserve the OneDrive copy until the local copy and backup are confirmed.

Copying first is slower but safer than moving thousands of files in one unverified operation.

Unlinking OneDrive is a separate action

Stopping folder backup affects selected Windows folders.

Unlinking the PC or quitting OneDrive affects synchronization more broadly.

Microsoft documents pausing, quitting, unlinking, hiding, and uninstalling OneDrive as separate controls.

Do not unlink or uninstall OneDrive while files are still downloading, uploading, or being relocated.

Work and school accounts

An administrator may enforce folder backup or prevent manual redirection.

Contact the organization before changing:

  • Managed Desktop
  • Work Documents
  • Shared files
  • Retention-controlled data
  • Files subject to legal or security policy

Do not move employer data into a personal account merely to regain control of a folder path.

Bottom line

Download cloud-only files, stop backup through Manage backup, and deliberately choose whether the files belong on the PC or in OneDrive.

Then verify the destination before deleting anything.

Cloud synchronization is very efficient at distributing both careful organization and catastrophic misunderstanding.
