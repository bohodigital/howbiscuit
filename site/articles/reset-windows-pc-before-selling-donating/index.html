How to Reset a Windows PC Before You Sell, Donate, or Recycle It

A routine Windows reset for troubleshooting is not the same as preparing a computer for a stranger. Use the data-cleaning option, verify the setup screen, and preserve anything needed before the reset begins.

Updated Aug 5, 2026 6 min read Researched Not hands-on tested
Disclosure

This article contains no paid or affiliate links.

Read the disclosure

What to know

  • A routine Windows reset for troubleshooting is not the same as preparing a computer for a stranger. Use the data-cleaning option, verify the setup screen, and preserve anything needed before the reset begins.
  • Back up files and authentication methods, use **Remove everything**, enable drive cleaning, stop at the initial setup screen, and remove the PC from your account.

Back up everything you need.

Then open:

Settings → System → Recovery → Reset PC

Choose:

  1. Remove everything
  2. Cloud download or Local reinstall
  3. Change settings
  4. Enable the option to clean data or fully clean the drive
  5. Complete the reset
  6. Stop when the first Windows setup screen appears

Microsoft specifically recommends resetting a Windows PC before selling, gifting, or recycling it and removing the device from the Microsoft account afterward.

Back up more than ordinary files

Preserve:

  • Documents
  • Photographs
  • Browser bookmarks
  • Email archives
  • Password-manager vault and recovery material
  • Authenticator transfers
  • BitLocker recovery key
  • Software license information
  • Application exports
  • Tax and business records
  • Game saves that are not synchronized
  • Wi-Fi or VPN configuration that will be needed elsewhere

Open representative files from the backup before erasing the computer.

A progress bar saying a copy finished is not quite the same thing as proving the files survived humanity’s latest encounter with a storage device.

Transfer authentication methods

Before erasing the PC, make sure important accounts can be accessed without it.

Check:

  • Authenticator application
  • Passkeys
  • Security keys
  • Recovery codes
  • Trusted-device approvals
  • Recovery email
  • Recovery telephone
  • Password-manager access

Do not reset the only device that can approve sign-in to the account containing the backup.

Disconnect removable storage

Remove:

  • USB drives
  • External hard drives
  • Memory cards
  • Backup drives
  • Security keys not required for the reset

This reduces the chance of erasing or confusing another storage device during the reset process.

Check BitLocker first

Open:

Settings → Privacy & security → Device encryption

and:

Control Panel → System and Security → BitLocker Drive Encryption

Preserve the recovery key before changing firmware, TPM settings, or the operating system.

BitLocker may request the 48-digit recovery key after a security or hardware change. Microsoft cannot reconstruct a recovery key that was never preserved in an accessible location.

You generally do not need to decrypt a normally functioning PC before using Windows’ supported ownership-transfer reset workflow.

Sign out and deactivate licensed applications

Review:

  • Microsoft 365
  • Adobe applications
  • Music or media authorizations
  • VPN
  • Password manager
  • Business software
  • Game launchers
  • Browser profiles
  • Cloud-storage clients

Some subscriptions limit the number of activated devices.

Deactivating the old installation before the reset can make the license easier to use on the replacement computer.

Disconnect work or school access

Open:

Settings → Accounts → Access work or school

Disconnect the organization account when the device belongs to you and organizational policy permits it.

Removing the account from Windows does not delete the underlying organization account; it removes that account’s connection and local data from the PC.

An employer-owned or school-owned device should be returned through the organization’s approved process rather than privately reset.

Start Reset this PC

Open:

Settings → System → Recovery → Reset PC

Choose Remove everything.

Do not choose Keep my files for an ownership transfer. That option is intended to preserve personal files while reinstalling Windows.

Microsoft describes Remove everything as the reset choice that removes personal files, applications, and settings.

Cloud download versus local reinstall

Cloud download

Downloads a fresh Windows image.

It can be useful when local recovery files may be damaged, but it requires a stable internet connection and additional data.

Local reinstall

Uses recovery files already on the PC.

It may be faster and avoids the large download.

Neither choice replaces the separate data-cleaning setting used when transferring ownership.

Enable drive cleaning

Open Change settings within the reset workflow.

Enable the option described as:

  • Clean data
  • Fully clean the drive
  • Clean the drive

Exact wording can vary by Windows release and device.

Microsoft says the full-cleaning option takes longer but makes deleted files harder for another person to recover and recommends it for donation, sale, recycling, or replacement.

This consumer reset process is not a certified enterprise sanitization report. Highly sensitive government, regulated, legal, medical, or corporate storage may require an organization-approved sanitize or destruction procedure.

Include every internal drive deliberately

Some computers contain more than one internal drive.

Review whether the reset applies to:

  • Windows drive only
  • Every internal drive

Do not choose until you know where personal files were stored.

A secondary internal data drive can quietly preserve years of information while the freshly reset Windows drive stands nearby looking innocent.

Let the reset finish

Keep the PC:

  • Connected to reliable power
  • Ventilated
  • Undisturbed

The computer may restart several times.

Do not force it off because the screen remains unchanged for a while unless Microsoft or the manufacturer’s recovery guidance specifically directs that action.

Stop at the setup screen

When Windows displays its first-time setup screen asking for a region, keyboard, or network:

  • Do not create another personal account.
  • Do not reconnect your Microsoft account.
  • Shut the PC down.

The next owner can complete setup.

Signing in again can restore synchronized settings, browser data, applications, or files and make it look as though the reset failed when the user has actually invited the cloud backup back inside.

Remove the device from your Microsoft account

After the reset:

  1. Sign into the Microsoft account from another trusted device.
  2. Open the device list.
  3. Find the old PC.
  4. Select Remove device.
  5. Unlink it from Microsoft Store device management when appropriate.

Microsoft recommends removing and unlinking a transferred PC from the account after the reset.

Also remove it from:

  • Password-manager trusted devices
  • VPN portal
  • Cloud backup dashboard
  • Employer-management system where authorized
  • Manufacturer support account

Physically inspect the machine

Remove:

  • SIM card
  • SD card
  • USB receiver
  • Security key
  • Privacy labels
  • Asset labels containing personal information
  • Notes hidden in a laptop sleeve

Include the correct charger only after checking it for damage and recall status.

Bottom line

Back up files and authentication methods, use Remove everything, enable drive cleaning, stop at the initial setup screen, and remove the PC from your account.

A computer is ready for another owner only when the new owner receives a setup screen rather than an archaeological tour of your browser sessions, tax records, and saved Wi-Fi networks.
