How to Set Up and Test File History in Windows 11

File History automatically saves changing versions of personal files to another drive. A successful setup screen is not enough; the backup should be tested through an actual restore.

Updated Aug 5, 2026 4 min read Researched Not hands-on tested
Disclosure

This article contains no paid or affiliate links.

Read the disclosure

What to know

  • File History automatically saves changing versions of personal files to another drive. A successful setup screen is not enough; the backup should be tested through an actual restore.
  • Turn on File History, confirm the folders and retention settings, and complete an actual restore test.

Connect an external drive, then open:

Control Panel → System and Security → File History

Select the backup drive and choose Turn on.

Windows 11 still manages File History through the traditional Control Panel. The feature watches supported personal folders and saves changed versions to an external drive or network location.

Do not trust the configuration until you create, change, delete, and restore a test file.

What File History protects

File History is designed around personal files associated with the Windows account, including supported libraries and folders such as:

  • Documents
  • Desktop
  • Pictures
  • Videos
  • Music
  • Favorites

It is not a full image of Windows. It normally does not preserve installed applications, product licenses, the entire operating system, or every file stored outside included libraries.

Use it beside, not instead of, a broader backup plan.

Choose a destination

Good destinations include:

  • External hard drive
  • External SSD
  • Supported network share
  • Network-attached storage folder

The destination should have substantially more free space than the data being protected because File History keeps multiple versions.

Do not use another partition on the same physical disk as the only destination. One hardware failure could destroy both the working files and their alleged backup, which is a very tidy way to lose everything.

Turn File History on

  1. Connect the external drive.
  2. Open Control Panel.
  3. Select System and Security.
  4. Select File History.
  5. Confirm the correct destination.
  6. Select Turn on.
  7. Allow the initial copy to finish.
  8. Keep the computer awake and powered during the first run.

When the desired drive is not shown, use Select drive. For a network destination, choose Add network location and enter the authorized share.

Review excluded folders

Open Exclude folders.

Exclude only data that:

  • Exists safely elsewhere
  • Can be recreated
  • Is intentionally outside the backup plan
  • Is too large for the destination and has another verified backup

Do not exclude an important folder merely because the first backup is taking longer than hoped. Large files are not less important because the progress bar finds them inconvenient.

Review frequency and retention

Open Advanced settings.

Depending on the current Windows version, File History can offer controls for:

  • How often copies are saved
  • How long versions are retained
  • Offline-cache behavior
  • Event-log access

Longer retention uses more capacity. Choose settings based on how frequently files change, how much space exists, and how far back a useful recovery may need to go.

Do not select indefinite retention without monitoring free space.

Perform a real restore test

Create a folder named:

File-History-Test

Inside it, create:

restore-test.txt

Enter a sentence and save it. Then:

  1. Let File History run.
  2. Edit the sentence and save again.
  3. Let another backup run.
  4. Delete the file.
  5. Open Restore personal files from File History.
  6. Browse to the test folder.
  7. Move through earlier versions.
  8. Restore the deleted file.
  9. Open it and verify its contents.

A restored file that opens is evidence. A green status screen is reassurance.

Restore to another location

Restoring over a current file can overwrite it. Where supported, right-click the restore button and choose an alternate destination.

This lets you compare:

  • Current version
  • Earlier version
  • Restored copy

A backup system should not require destroying the present file merely to inspect the past one.

Check that backups continue

At least monthly:

  • Open File History.
  • Confirm the destination is connected.
  • Review the latest backup time.
  • Restore a test file.
  • Check available space.
  • Inspect the drive for errors.

File History cannot write to a drive that has lived in a drawer for six months because the cable was aesthetically offensive.

Protect against ransomware, theft, and fire

An always-connected writable backup can be affected by malware, ransomware, power events, theft, liquid damage, or fire.

A stronger arrangement has three copies:

  1. Working copy
  2. File History copy
  3. Separate offline or off-site copy

Disconnecting an external drive between scheduled sessions can reduce some risks, provided someone reliably reconnects it.

Bottom line

Turn on File History, confirm the folders and retention settings, and complete an actual restore test.

File History is useful versioned backup for personal files. It is not a full system image, and it is not proven until a deleted file returns intact.
