Home Generator Maintenance, Test, Fuel, and Outage Log Template

Portable and permanently installed generators have different operating and maintenance requirements. Every interval and procedure should come from the exact manufacturer manual.

Updated Aug 5, 2026 3 min read Researched Not hands-on tested
Disclosure

This article contains no paid or affiliate links.

Read the disclosure

What to know

  • Portable and permanently installed generators have different operating and maintenance requirements. Every interval and procedure should come from the exact manufacturer manual.
  • Record every inspection, test, fuel change, maintenance event, operating hour, and outage.

Create one permanent record for each generator.

Never operate a portable generator indoors, in a garage, basement, crawlspace, shed, porch, or carport.

Operate it outdoors at least 20 feet from homes and other occupied structures, with exhaust directed away from doors, windows, and vents.

Never connect a portable generator to household wiring through an ordinary receptacle.

Backfeeding can energize utility lines, damage equipment, and expose workers or neighbors to lethal voltage.

Use approved transfer equipment installed according to code and manufacturer instructions.

Store fuel in approved containers, away from ignition sources and occupied living areas, according to local fire code.

Never refuel a running or hot generator.

Fuel stabilizer can extend storage life but cannot restore gasoline that is already stale.

Scheduled test

| Date | Start method | No-load result | Test load | Voltage | Frequency | Runtime | Fault | |---|---|---|---|---|---|---|---| | | | | | | | | |

For a planned test:

  1. Move a portable generator to its approved outdoor location.
  2. Inspect it.
  3. Confirm CO alarms work.
  4. Start it according to the manual.
  5. Allow stabilization.
  6. Apply an approved test load.
  7. Observe for leaks, smoke, noise, or faults.
  8. Remove loads.
  9. Stop it normally.
  10. Record the result.

Do not run a gasoline generator inside because the test is short. Carbon monoxide is not impressed by limited scheduling.

Never exceed running watts, surge watts, outlet rating, cord rating, or transfer-equipment rating.

Cleaning

Use the exact approved cleaning method.

Keep cooling openings clear, controls dry, dirt away from fuel fill, and combustibles away from exhaust.

Do not use a garden hose unless the manual explicitly permits it. Water can damage engine and generator windings.

Standby generators

Record:

  • Automatic exercise date
  • Exercise result
  • Battery condition
  • Fuel supply
  • Dealer service
  • Fault code
  • Remote-monitor status
  • Transfer-switch service

A successful weekly exercise does not prove the home can carry the intended outage load.

Bottom line

Record every inspection, test, fuel change, maintenance event, operating hour, and outage.

The generator should be boring before the emergency. Discovering stale fuel, a dead battery, missing adapter, and an untested transfer switch after the lights go out is a more cinematic experience than the household needs.
