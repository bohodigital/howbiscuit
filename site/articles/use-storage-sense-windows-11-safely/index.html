How to Use Storage Sense in Windows 11 Without Deleting Files You Need

Storage Sense can clear temporary files and age out Recycle Bin contents automatically. Downloads and cloud files are treated separately, so review every option before enabling scheduled cleanup.

Updated Aug 5, 2026 5 min read Researched Not hands-on tested
Disclosure

This article contains no paid or affiliate links.

Read the disclosure

What to know

  • Storage Sense can clear temporary files and age out Recycle Bin contents automatically. Downloads and cloud files are treated separately, so review every option before enabling scheduled cleanup.
  • Leave Downloads cleanup off, use a reasonable Recycle Bin period, protect required OneDrive files with **Always keep on this device**, and test Storage Sense manually.

Open:

Settings → System → Storage → Storage Sense

For the safest starting configuration:

  • Leave Downloads cleanup set to Never.
  • Give Recycle Bin files a generous retention period.
  • Review OneDrive cloud-content settings.
  • Run Storage Sense manually once before scheduling it.
  • Back up irreplaceable files independently.

Microsoft says Storage Sense primarily removes temporary files and Recycle Bin contents. It does not clean Downloads or convert cloud files to online-only unless those options are deliberately configured.

Review what is using the drive first

Open:

Settings → System → Storage

Windows separates used space into categories such as:

  • Installed apps
  • Temporary files
  • Documents
  • Pictures
  • Other
  • System and reserved
  • OneDrive or cloud content

Open each large category before deleting anything.

A full drive can result from:

  • Large application
  • Video collection
  • Old Windows installation
  • Downloaded update files
  • Game library
  • Virtual machine
  • Cloud files retained locally
  • Duplicate backup

Storage Sense helps with disposable material. It does not identify every large personal file as unnecessary merely because the drive would prefer more room.

Turn on automatic cleanup carefully

Under Storage Sense, enable:

Automatic User content cleanup

Then choose when it runs.

Microsoft currently supports schedules such as:

  • Every day
  • Every week
  • Every month
  • During low free disk space

The default behavior generally favors running when Windows detects low disk space. Storage Sense operates on the system drive and normally runs while the user is signed in and the computer has been online long enough to complete its work.

A weekly schedule may be useful on a small SSD. A larger computer with ample capacity may need only low-space cleanup.

Protect the Downloads folder

Find:

Delete files in my Downloads folder if they haven’t been opened for more than

Set it to Never unless Downloads is already treated as temporary storage.

Downloads often contains:

  • Tax forms
  • Drivers
  • Installer files
  • Signed PDFs
  • Receipts
  • Medical records
  • Research papers
  • Photographs transferred from another device

“Not opened recently” does not mean “unneeded.”

A file can remain important precisely because it is being kept for later rather than opened every Tuesday to reassure Windows of its emotional significance.

Choose a Recycle Bin retention period

Storage Sense can delete Recycle Bin contents after a chosen age.

A practical starting point is:

  • 30 or 60 days for ordinary household use
  • Longer when accidental deletion is a recurring problem
  • Never when another process reviews deleted material manually

Remember that the Recycle Bin is not a backup.

Files can bypass it when:

  • Deleted from certain external drives
  • Removed from network storage
  • Deleted with Shift + Delete
  • Deleted by some applications
  • Too large for the configured bin

Keep an actual backup even with generous retention.

Understand cloud-content cleanup

Storage Sense can convert supported OneDrive files from locally available copies into online-only files after they have not been opened for a configured period.

That frees disk space without deleting the cloud copy.

Microsoft says files marked Always keep on this device are excluded from automatic online-only conversion.

Before enabling cloud-content cleanup, identify files needed during:

  • Internet outage
  • Travel
  • Field work
  • Account lockout
  • OneDrive outage
  • Computer repair
  • Emergency

Right-click those files or folders and choose:

Always keep on this device

Then wait for the local-download indicator to appear.

Online-only is not the same as backed up

An online-only file can remain visible in File Explorer even though its content is not stored locally.

Opening it requires:

  • Internet access
  • Working OneDrive client
  • Valid account session
  • Available cloud copy

Synchronization can also propagate deletions.

Maintain an independent backup for irreplaceable files rather than relying on one synchronized cloud account.

Run Storage Sense manually first

After configuring the options:

  1. Record available disk space.
  2. Close important applications.
  3. Select Run Storage Sense now.
  4. Wait for completion.
  5. Review available space again.
  6. Check Downloads.
  7. Check the Recycle Bin.
  8. Open representative OneDrive files.
  9. Confirm required offline files remain local.

A controlled manual run reveals what the selected settings actually do before automation repeats them indefinitely.

Review Cleanup recommendations separately

Open:

Settings → System → Storage → Cleanup recommendations

Windows may suggest:

  • Temporary files
  • Large or unused files
  • Files synchronized to the cloud
  • Unused applications

Review every item individually.

Microsoft describes Cleanup recommendations as a review interface rather than an instruction to delete every listed object.

An “unused” application may be:

  • Tax software
  • Emergency utility
  • Printer configuration tool
  • Annual reporting program
  • Accessibility tool
  • Device firmware application

When Storage Sense is not enough

For persistent low-storage warnings:

  • Uninstall applications no longer used.
  • Move personal video archives.
  • Remove old virtual machines.
  • Relocate game libraries.
  • Check for duplicate backups.
  • Upgrade storage where supported.
  • Investigate abnormal system-file growth.

Do not use an unknown registry cleaner or “one-click optimizer.” Deleting unexplained system files can create substantially more work than purchasing additional storage.

Bottom line

Leave Downloads cleanup off, use a reasonable Recycle Bin period, protect required OneDrive files with Always keep on this device, and test Storage Sense manually.

Automatic cleanup should remove material you have already classified as disposable. It should not be asked to infer which quiet old PDF contains the only copy of something important.
