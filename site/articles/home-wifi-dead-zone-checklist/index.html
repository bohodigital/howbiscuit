A Wi-Fi dead zone is easier to fix when you record what changes from room to room.

This checklist helps you separate:

  • Internet-service problems
  • Router-placement problems
  • Weak coverage
  • One-device problems
  • Interference
  • Band-selection problems

Download: Home Wi-Fi Dead-Zone Checklist (PDF)
Printable PDF, no email address required.

Before you start

Gather:

  • One primary test device
  • One second device
  • Router and modem model numbers
  • Wi-Fi password
  • Notebook or printable checklist
  • Ethernet cable, if already available
  • Router or ISP app, if used
  • Manufacturer manuals

Pause:

  • Large downloads
  • Game updates
  • Cloud backups
  • Unnecessary streaming
  • VPN, if safe and permitted, for a comparison test

Do not expose passwords, public IP addresses, device serial numbers, or private network details in screenshots.

Part 8: Restart and update

  • Restarted modem and router using supported instructions
  • Checked router firmware
  • Checked automatic-update setting
  • Updated test device
  • Updated computer Wi-Fi driver through official source
  • Confirmed router still receives security support
  • Did not factory-reset

Part 9: Separate Wi-Fi from internet service

  • Tested by Ethernet
  • Ethernet is healthy
  • Ethernet is also slow
  • Modem status lights normal
  • ISP outage checked
  • Every device affected
  • Only distant rooms affected

Likely category:

  • Device problem
  • Wi-Fi coverage problem
  • Router problem
  • Modem or provider problem
  • Interference or congestion
  • Unclear; more observation needed

Part 10: Decide the next action

Keep testing free changes when:

  • Moving the router improved the worst room
  • Another band improved stability
  • One device is the only problem
  • An obstruction can still be removed
  • Existing Ethernet can serve fixed devices

Contact the ISP when:

  • Ethernet is also slow
  • Every device loses internet together
  • Modem lights show a fault
  • Provider equipment cannot update
  • Repeated tests remain far below the plan

Consider additional hardware when:

  • Important rooms remain weak after placement changes
  • Building materials block the signal
  • Router cannot be relocated
  • Existing Ethernet could support an access point
  • One access point cannot cover the required area

Safety and privacy notes

  • Keep passwords off the printed checklist.
  • Do not photograph labels that expose default credentials or serial numbers.
  • Do not disable WPA2 or WPA3 security.
  • Do not use unknown firmware.
  • Do not open network equipment.
  • Do not place indoor equipment where it can get wet.
  • Back up settings before major changes.
