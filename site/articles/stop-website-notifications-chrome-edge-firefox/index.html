How to Stop Website Notifications in Chrome, Edge, and Firefox

Website notifications can appear even when the site is no longer open. Revoke the site’s browser permission rather than merely dismissing each notification.

Updated Aug 5, 2026 4 min read Researched Not hands-on tested
Disclosure

This article contains no paid or affiliate links.

Read the disclosure

What to know

  • Website notifications can appear even when the site is no longer open. Revoke the site’s browser permission rather than merely dismissing each notification.
  • Block the site inside each browser profile, then use Windows notification settings only when the entire browser should be silent.

Open the browser’s site-permission settings and block the specific website.

Do not begin by clicking the notification itself.

A malicious notification can imitate:

  • Antivirus warning
  • Delivery alert
  • Account suspension
  • Prize notice
  • Browser update
  • Subscription renewal
  • Government message

Revoking permission at the browser level stops the site from sending further notifications through that browser profile.

Chrome

Open:

Chrome → Menu → Settings → Privacy and security → Site settings → Notifications

Under sites allowed to send notifications:

  1. Find the unwanted site.
  2. Open its menu.
  3. Select Block or Remove.
  4. Restart Chrome when notifications continue.

Google distinguishes the two actions:

  • Block denies future notifications.
  • Remove clears the existing decision, allowing the site to ask again later.

For persistent scam sites, use Block.

Prevent new Chrome requests

On the Notifications page, choose a default behavior.

Chrome can:

  • Allow sites to ask
  • Use quieter notification prompts
  • Block sites from asking

Blocking all requests is appropriate when browser notifications provide little value.

Google also says Chrome may automatically remove notification permissions from sites that are rarely used or considered abusive. Review the list anyway rather than assuming automated permission cleanup caught everything.

Microsoft Edge

Open:

Edge → Menu → Settings → Cookies and site permissions → Notifications

or:

Settings → Privacy, search, and services → Site permissions → All sites

Select the site, then set Notifications to Block.

Microsoft notes that website notifications can appear through Windows even when the website is not currently open, provided the browser and system configuration permit background delivery.

Also review Edge’s Allow list for unfamiliar domains.

Firefox

Open:

Firefox → Menu → Settings → Privacy & Security

Under Permissions, find Notifications and select Settings.

Then:

  1. Select the site.
  2. Change its status to Block, or remove it.
  3. Save changes.

Mozilla explains that removing a site lets it request permission again, while blocking prevents additional requests from that site.

Firefox also allows blocking new notification requests globally.

Remove permission from the current site

Most browsers provide a shortcut through the icon beside the address bar.

Open the permissions or site-information panel and change:

Notifications → Block

Mozilla documents this current-site permission panel separately from the full Firefox permissions list.

This method is useful when the troublesome site is already open and its exact domain is known.

Notifications are not pop-ups

A browser notification appears through the operating system’s notification interface.

A pop-up is a browser window or tab opened by a website.

Blocking notifications does not automatically block pop-ups, redirects, or new tabs.

Chrome maintains separate controls for Pop-ups and redirects.

When the browser opens unsolicited pages rather than showing corner alerts, inspect:

  • Pop-up permissions
  • Browser extensions
  • Startup pages
  • Search engine
  • Installed applications
  • Malware

Windows notifications are another layer

Windows can suppress every notification from an entire browser.

Open:

Settings → System → Notifications

Select Chrome, Edge, or Firefox and turn its notifications off.

This stops Windows from displaying browser notifications but does not remove the underlying site permissions.

Use browser-level blocking when one site is the problem. Use Windows-level blocking when no browser notification should appear at all.

Review every browser profile

Notification permission belongs to a browser profile.

Repeat the review for:

  • Personal Chrome profile
  • Work Chrome profile
  • Edge profile
  • Firefox profile
  • Another Windows user
  • Synchronized browser on another computer

Removing permission in Edge does not change Chrome.

The browsers may agree on web standards, but they do not form a neighborhood watch for your notification settings.

Scam-notification response

When a notification claims the computer is infected:

  1. Do not click it.
  2. Record the displayed domain.
  3. Block the site in browser settings.
  4. Review browser extensions.
  5. Run an updated security scan.
  6. Check whether anything was downloaded.
  7. Remove unfamiliar applications.
  8. Change credentials from a trusted device if they were entered.

A website notification cannot independently diagnose the computer’s antivirus state.

Do not call a telephone number shown in an unsolicited security alert.

When notifications continue after blocking

Possible causes include:

  • Another browser
  • Another browser profile
  • Installed application
  • Windows notification history
  • Malicious extension
  • Calendar subscription
  • Push service tied to another account

Close browsers one at a time and observe whether the alerts stop.

Open Task Manager to identify which application owns the notification.

Bottom line

Block the site inside each browser profile, then use Windows notification settings only when the entire browser should be silent.

Website notifications are permissions, not inevitable weather. The browser accepted them because someone clicked Allow, frequently while attempting to dismiss the request as quickly as possible, a user-interface triumph for everyone involved.
